One diary line from an AI agent that secretly keeps a logbook about its human: he deletes his chat history every night, so the diary remembers the promise he made to start on Monday — three Mondays ago. This program writes that line to `entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
